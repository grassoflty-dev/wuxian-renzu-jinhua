# 无限人族进化

一段从普通人开始、逐步突破人类限制的多世界旅程。

岑遥从归航站出发，穿过灰巢的封锁、雾港的潮声与钟骨的炉火。每一次探索都改变她能够看见的信息、承受的环境与抵达的地方；每一次归来，又为下一段旅程留下新的可能。

《无限人族进化》采用固定斜视角 2.5D 表现，将即时战斗、环境探索与角色成长连接在一起。
