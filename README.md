# 无限人族进化

## 游戏介绍

《无限人族进化》是一款原创无限流动作角色扮演游戏，采用固定斜视角 2.5D 表现，以工业科幻与多世界探索为背景。

玩家扮演普通人类探索者岑遥，从连接未知世界的小型技术中继站“归航站”出发。每个世界都有自己的环境、危险与规则：在连续场景中探索、战斗、操作设施、完成目标，再返回归航站保存成长，准备下一次旅程。

游戏的成长主轴是“逐步解除普通人的限制”。获得能力会改变你能看到的信息、承受的环境压力，以及理解和穿越世界的方式；新的能力也为有限重访提供不同的解法。

### 核心玩法

- 即时战斗：结合普通攻击、冲刺、Pulse 脉冲、Guard 防御和 Pierce 穿刺，观察敌人预警，选择进攻或防守时机
- 场景探索：恢复供电、解除封锁、调整泵站与阀门，在环境危险和机械结构中寻找通路
- 信息成长：地图、后方感知与敌方状态等玩法信息随能力开放，让感知本身成为成长的一部分
- 跨世界推进：从归航站依次进入灰巢设施、雾港余烬和钟骨工厂，在世界之间保留成长与进度

### 三个世界

**灰巢设施（Grey Hive）**

一座因感染与生物安全事故而封锁的工业设施。玩家从维修入口深入动力间、中央竖井、生物隔离区和深层去污区，恢复主电、解除封锁，并面对重型设施守卫 Sentinel。它建立普通探索者面对未知危险时的生存起点。

**雾港余烬（Mist Harbor）**

被海雾、潮水、失效信号与异常共振笼罩的工业港区。玩家沿港口追踪信标和信号，处理泵站水位，在视野受限、声音线索与水域移动的变化中寻找方向。

**钟骨工厂（Clockworks）**

由熔炉、高压蒸汽、传送带、升降结构和巨大机械组成的自动化工厂。压力控制、热量管理与移动平台共同影响行进和战斗，旅程最终抵达调节器核心。

### 角色成长

灰巢首次通关后，玩家可在本地地图、后视感知和身体再生中选择首次强化。三世界成长还围绕敌方生命体征、声学映射和空踏展开：信息能力帮助理解威胁，移动能力用于特定场景通路，空踏不等于自由飞行。

更多血统、装备、技能和高级能力是长期扩展方向。当前预览版仍有占位表现，完整美术动画、部分剧情与档案、完整能力树界面和无障碍设置尚待完善，不能将设计文档中的全部目标视为本版已交付功能。

## 灰巢 Godot 首个可玩版：玩家入门（开发中）

本节对应当前 Godot 灰巢入口。下方 preview.5 下载与验证统计保留为旧版 WebView2 发布记录，不能作为本入口的运行包或验收证据。

状态：部分私有候选已完成隔离启动、保存与新进程继续的局部验证；真实按住移动与完整灰巢首通尚未完成实测。当前不能据此宣称首个可玩版已完成或已发布。

### 启动前

需要 Windows、PowerShell Core 7.4 或更新版本（不是 Windows PowerShell 5.1），以及与当前源码匹配并经核验的原生权威程序、Godot 程序和游戏工程。具体参数、目录要求和启动方式见[持久玩家启动器说明](tools/grey-hive-player/README.md)；[入口契约](docs/releases/grey-hive-player-entry.md)供交付者核对。说明中的占位符不能直接运行。

当前正常入口是 Godot 工程的主场景。跨次启动保留同一个玩家 ProfileRoot 与 session/saves，每次启动使用新的 AttemptDir；不要把旧版 WebView2 存档复制进来。若启动器报告状态不确定或遗留会话，请保留现场与存档，交由交付者排查。

### Windows 发行包说明

当前为私有候选，尚未发布；首个可玩版尚未完成实测。本节说明当前便携入口，不是下载承诺或完整通关验收结论。

发行包可用时，请解压完整目录后运行 `Play.cmd`，不要单独拷贝 EXE。入口使用包内运行时；正常外置用户存档配置位置为 `%LOCALAPPDATA%/WuxianGreyHivePlayer`，不在解压目录中。不要移动已使用的玩家配置或混入旧版存档。

退出时使用正常菜单的“保存并退出”并等待确认；下次重新运行 `Play.cmd`，在同一玩家配置中选择“继续”。启动器正常退出本身不证明保存成功，保存与继续操作仍以下方说明及当前界面确认为准。

可选“鼠标移动面板”默认关闭，开关仅对本次会话生效。启用后按住箭头移动，松开或移出按钮停止；暂停、失焦或换景会取消当前鼠标移动，恢复后须松开再重新按下。面板不提供自动行走，键盘移动优先。

已知验证限制：一次自动化拖动记录的按下到松开约为 1 毫秒，未建立真实按住移动或完整灰巢路线的通过证据；面板源码与夹具通过不能替代这些实测。

Q 固定用于现有 Pulse 脉冲，受当前动作与能力条件限制，不是移动键。

### 第一段旅程

连接成功后选择“新的旅程”，阅读未保存进度提示后再确认；已有存档则通过“继续”选择当前显示可用的默认存档或命名槽位。

从归航站靠近灰巢入口，按 F 查看当前交互。进入后按 T 查看任务，沿可用通路恢复主电、处理隔离封锁，再依据当前任务和交互提示收取信标、进行撤离并返回归航站。信标部署为可选；门、距离与交互是否可用，以游戏当前提示为准。本段入门范围为归航站与灰巢，不代表其他世界已完成验收。

需要保存时按 Esc 打开“保存”，选择“保存当前默认存档”或可写的命名槽位；退出使用“保存并退出”并等待确认。保存失败或结果未知时保留当前会话，不把窗口关闭或进程正常退出当作保存成功。下次在同一玩家配置中选择“继续”，仅使用游戏确认可用的存档。

以上操作来自当前界面与入口源码；局部启动、保存与继续的观察不替代真实按住移动及完整首通验收，本文不提供完整首通的通过证明。
