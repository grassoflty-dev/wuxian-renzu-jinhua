3. 为什么不是纯“科幻玻璃 HUD”

所谓科幻玻璃 HUD，大概是：

透明玻璃
发光蓝边
大量悬浮信息
透明面板
高科技线框

它很好看，但作为《无限人族进化》主风格会有三个问题：

第一，太像“高级未来文明”。

玩家一开始只是普通人，人类文明不应该给人一种：

已经是超高度未来文明

的感觉。

第二，透明 UI 容易和高细节背景抢信息。

第三，三个世界如果全用纯蓝玻璃 HUD，会让世界差异变弱。

所以我们保留它的：

* 清晰；
* 科技；
* 轻量；
* 发光反馈；

但容器、框架、按钮采用：

更实在的工业终端材质。

106. 给 Codex 的正式视觉原则

以后直接把下面这段放进项目文档即可：

《无限人族进化》V1 采用固定斜视角高精度电影感 2.5D。全局 UI 使用“工业战术终端”视觉语言：深黑蓝/钢灰为底、科技青表达系统信息、暖金表达当前目标和可交互项、危险红只表达伤害与错误。

所有世界共用同一个 HUD 和 Meta UI 信息架构。Grey Hive 使用工业设施/冷蓝科技风；Mist Harbor 在统一框架上增加航海、声呐、雾与信号元素；Clockworks 增加黄铜、压力表、炉火与机械结构。

正式 UI 使用 HTML/CSS 实现，不能直接使用 AI 生成的整屏 UI 图片。PixiJS 负责角色、场景、世界内标记、VFX、遮挡和动画。AI 视觉图仅作为构图、色彩、材质和组件设计参考。

正式角色岑遥必须保持短黑发、深炭灰短外套、青灰内层、非对称暗金肩部结构、胸前金色菱形信标、深色工装裤和工业作战靴，不允许沿用长发、红披风、露肤幻想女战士方向。

核心战斗动作必须具备明确的身体运动和可读轮廓。Pulse 使用环形扫描语言，Guard 使用前方弧盾语言，Pierce 使用线性穿透语言，Dash 使用短距离残影语言，四者不得仅通过换颜色区分。

世界场景采用 Hero Scene Plate + Modular Props + Sprite Actor。正式场景必须具备背景、地面、后景物、角色、动态物、前景物、遮挡层、VFX 和 World UI 分层。

所有交互对象必须优先依赖设备自身造型与功能灯识别；靠近后才显示小型金色标识和 F 交互提示，不允许在世界里永久描亮所有可交互对象。

能力获得会实际改变 UI 信息。未获得 Local Map 时不显示小地图；未获得 Enemy Vitals 时不显示敌人 HP；Rear View 只在能力取得后出现；Accessibility 永远不属于能力解锁。
