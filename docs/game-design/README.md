# 无限人族进化

## 世界设定集

[打开图文版](index.html) · 下载本目录后，可直接用浏览器打开 index.html。所有插图均随本目录保存。

人类的世界，始于能够看见与抵达的地方。

岑遥从归航站出发，走进封锁的设施、被雾吞没的港口与仍在运转的机械工厂。她起初只是一个普通人：看不见身后的危险，无法判断远处的声音，也无法越过每一道断路。旅程给予她的，不只是更强的力量，还有认识世界的新方式。

这是一个关于探索、成长与突破人类限制的多世界动作角色扮演故事。工业设施的冷光、未知环境的压力与逐渐改变的身体，共同构成《无限人族进化》的世界。

### 第四章 · 超越限制

[玩法与成长](gameplay.md)

战斗与行动、感知与地图、技能与血统。能力如何改变一个人能够理解、承受和穿越的世界。
