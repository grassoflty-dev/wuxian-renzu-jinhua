# Player presentation corrections for the Windows preview

Baseline: 43035ecc2be2707e2e5a006273f8692c88938166. This slice changes presentation and pointer projection only; combat values, progression, saves and approved image bytes are unchanged.

- WASD remains screen-relative movement. Mouse input remains the Rust-owned combat facing. Moving sideways with a fixed mouse is intentional; the walking deformation does not steer attacks.
- Pointer input uses the actual player footpoint in the last successfully displayed frame, including camera lead, CSS scaling and elevated Y. An undrawn newer snapshot, cancelled scene, failed draw or resized buffer cannot supply an aim anchor. Before any pointer event there is no invented north aim. An eight-CSS-pixel deadzone retains the authority's previous facing.
- The eight approved Cenyao idle directions remain separate textures. A temporary MeshPlane deforms only the lower legs using authoritative displacement, velocity and tick deltas. The torso stays fixed. This is a bounded procedural gait, not finished authored walk/run/attack animation. Stop, pause, entry hold, death, teleport and owner replacement reset it. Reduced motion uses a small static stance.
- Player mesh and contact shadow use the same displayed footpoint and physical container as the neutral sprite. World sorting depth and displayed Y are distinct: elevated feet use the latter. Temporary Brute, Swarm and Signal Wraith bodies retain the selected crop anchor; their shadows use the displayed elevated feet as well. The mesh owns its geometry/buffers and never destroys the shared atlas textures.
- Worker, Security and Sentinel sources are eight-pose sheets. Each now selects one explicitly measured front pose from its existing approved atlas, with a pinned original source SHA and foot anchor. These are temporary static actor poses. The shipped Drowned v2, Signal Wraith v2 and Forged Guard v2 sources were inspected and are single portraits. Unknown actor sheets require explicit frame review; a whole unreviewed collection cannot silently become a single actor.
- Truthful contact feedback can tint the player mesh and its neutral sprite together. Clearing feedback restores the recorded normal tint, including colored enemy placeholders; each new frame, pause and owner replacement clears that ownership safely.
- Twenty-four static actor previews in eight Grey Hive scenes are explicitly bound to their existing canonical spawn IDs. Matching type/asset and exact authored position are also required. Only those previews are suppressed; the authoritative actor owns movement and death. Other decorative sprites are preserved.

Validation: TypeScript compilation and 79 focused model, real Pixi object, scene-session, input and renderer tests pass. They include eight-direction geometry, no triangle folding, private buffer cleanup, pause/stop/entry ownership, raised feet, failed/delayed draw, fixed-pointer reprojection, exact actor-source coverage and removal of dead/moved duplicate previews. The full Web regression also passes 629 tests with 4 platform-dependent skips (633 total), including the final cropped-placeholder and elevated-shadow regression. This does not constitute native Windows visual acceptance. Map/depth composition and QER contact feedback are separate paired slices.
